# 2D--flow-simulation-laminar-and-steady-
A 2D FVM Simulation code created with Python in Spyder
Created in my final uni year for my bachelor thesis. Feel free to use as starting point for future projects!
It's a 2D flow simulator for steady and laminar flow around a square or circle. It has a 1. Order upwind for convection and 2.Order CDS for diffusion aswell as SIMPLE. There are not a rhie-chow or staggered grid.
